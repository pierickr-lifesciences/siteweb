Générer l'empreinte du code d'aperçu

Le calcul se fait uniquement dans votre navigateur : le code n'est envoyé nulle part.

  1. Collez l'empreinte dans Pages CMS → Textes du site → Identité → Empreinte du code d'aperçu, puis Save.
  2. Notez le code lui-même dans un endroit sûr (gestionnaire de mots de passe).
  3. Pour voir le site en construction : ouvrez www.lifesciences-ip.com/?apercu=VOTRE_CODE une fois sur chaque appareil.
